What the buttons do: Open the publisher’s download or support page. Download the installer there, then run it yourself. A browser cannot silently reinstall everything. This file opens offline; downloads and account recovery require internet. It contains no installers, personal files, passwords or license keys.

1. Prepare before a failure

  • Copy this HTML to an external drive and cloud storage. Keep a separate backup of Documents, Desktop, Pictures, videos, projects and game saves.
  • Keep account recovery methods, software licenses and your BitLocker/device-encryption recovery key in a secure place separate from this file. Never put wallet recovery phrases here.
  • Export OBS scenes/profiles, VoiceAttack profiles, Twine stories and other app settings. Back up local AI models/chats, virtual machines and Docker volumes if you need them.
  • Save original installers for the items marked “Needs your installer.” Optional: keep other downloaded installers on the USB for offline recovery.
  • Create Windows installation media now using Microsoft’s Windows download page. Use an empty USB of at least 8 GB; creating installation media erases that USB. Confirm your Windows edition in Settings → System → About and activation in Settings before creating a recovery plan.

2. Restore in this order

  1. Recover Windows first. If Windows will not start, open this HTML on another computer. Back up recoverable files before resetting or reinstalling. Boot from your prepared installation USB and try repair options first. A clean install or deleting partitions can erase files. Reinstall the edition covered by your license.
  2. Get connected. Install your exact model’s HP networking and system drivers. If Wi-Fi is unavailable, use another PC to download the network driver to USB. Run Windows Update, restart, and repeat as needed.
  3. Install graphics and core apps. Install NVIDIA drivers, your browser, Office and OneDrive. Sign in using your existing accounts.
  4. Restore the rest. Use the cards below. Install Steam before its games and VoiceAttack. Install development tools before rebuilding project environments.
  5. Restore your files. Reconnect backups, restore projects/settings and check that important files open. App installation alone does not restore your data.

3. Your reinstall library

Use search or categories to find a program. Check items off as you restore them. Checks are saved in this browser when local storage is available; moving the HTML or using a different browser may reset them.
